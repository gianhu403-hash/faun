# Research-report: распознавание видов птиц для пилота Faun

**Дата:** 2026-06-11
**Контекст задачи:** офлайн batch-распознавание видов птиц по записям пассивных ловушек (WAV 48 kHz stereo), заповедник СЗ России. Вычислитель — RTX 2060 SUPER 8 GB, но критическое ограничение: **TF/JAX = CPU-only** (установлен torch cu130 / CUDA 13.0, несовместимый с CUDA 11.8, которую требует TF GPU). PyTorch-модели идут на GPU, TensorFlow/JAX-модели — только на CPU.
**Цель точности:** ~70–80% без ground-truth разметки.

> Помечаю неопределённости явно. Где число — оценка, а не измерение на нашем железе, пишу «оценка».

## 2. Ранжированная рекомендация классификатора

### #1 — Perch 2 (perch_v2_cpu через bioacoustics-model-zoo) — рекомендую для пилота

**Обоснование:**
- **Лицензия Apache 2.0** снимает юридический риск. Если у пилота есть хоть какой-то коммерческий горизонт (продукт Faun — это коммерческий кейс-чемпионат, не чистый research), BirdNET CC BY-NC-SA становится миной: запрещает коммерцию и заражает (ShareAlike) любые дообученные головы.
- **Лучшие эмбеддинги** (1536-мерные, SOTA на BirdSet/BEANS) → решает главную боль задачи: **нет ground-truth разметки**. Few-shot k-NN на эмбеддингах позволяет распознавать редкие виды (соня, выхухоль) без обучающих меток.
- Покрывает не только птиц — полезно для общего биоакустического мониторинга заповедника.
- **Цена входа:** бесплатный Kaggle-аккаунт + kaggle.json (~15 минут).
- **Риски:** RTF на x86 CPU не измерен публично (для нашего batch-офлайн некритично); требует TF ≥ 2.20 в изолированном venv (`pip install tensorflow-cpu` отдельно от torch, чтобы не конфликтовать с cu130).

### #2 — BirdNET-Analyzer v2.4.0 — отличный, но с лицензионным флагом

**Обоснование:**
- Самый **зрелый и готовый**: `pip install birdnet-analyzer`, анонимная загрузка, нативный 48 kHz stereo — нулевая предобработка, RTF ~0.013 (быстро на CPU).
- 6 511 видов, полное покрытие зап.-палеарктики — почти наверняка лучше «из коробки» по списку видов СЗ России.
- **Блокер:** CC BY-NC-SA 4.0 на моделях. Для чисто природоохранного/исследовательского применения без монетизации — фактически разрешено и риск низкий. Для коммерческого пилота — нужен явный запрос в Cornell (ccb-birdnet@cornell.edu), а ShareAlike заражает дообученные головы.
- **Практический совет:** использовать BirdNET для **быстрой валидации списка видов этой ночью** (анонимно, без барьеров), но строить продуктовый пайплайн на Perch 2.

### #3 — YAMNet v7 (наша) — только как CPU-эмбеддер, не классификатор

Голова под 6 антропогенных классов, видов птиц не распознаёт. Ценность нулевая для видовой задачи; может служить дешёвым baseline-эмбеддером для сравнения, но Perch/BirdNET эмбеддинги строго лучше.

**Итоговая рекомендация:** Perch 2 как продуктовый классификатор/эмбеддер (Apache 2.0, few-shot), BirdNET как быстрый оценочный инструмент видового списка (учитывая NC-лицензию для не-коммерческого использования).

## 3. Детектор 1-го этапа: onset+NDSI vs CLAP

**Рекомендую: onset.py (RMS + adaptive baseline) как stage-1, CLAP как опциональный stage-2 верификатор.**

| | onset.py (RMS+baseline) | NDSI | CLAP zero-shot |
|---|---|---|---|
| Железо | CPU, numpy, мгновенно (RTF >> 100x) | CPU, мгновенно | **GPU** (torch cu130, ~330 MB VRAM, 3–5 c/10-мин клип) |
| Зависимости | нет весов | нет весов | `pip install laion-clap`, веса с HF анонимно (CC0) |
| Назначение | event-level onset (<10 c) | биоактивность на шкале **минут** (разрешение ~1 мин) | бинарь «птица/не-птица», AP 0.84–0.98 |
| Слабость | высокий FPR на ветер/дождь/монотонный фон | **не для event-детекции <10 c** | требует prompt-инжиниринга, GPU |

**Логика:**
- **onset.py** — детерминирован, CPU, нулевые зависимости, убирает >80% тишины мгновенно. Это правильный быстрый первый фильтр.
- **NDSI непригоден** как onset-детектор: его временное разрешение ~1 минута. Применять только как pre-filter на уровне минутных блоков («активный/неактивный сегмент»), не для выделения окон <10 c.
- **CLAP** — мощный, но это GPU-инференс и prompt-инжиниринг. На нашем железе CLAP — единственное, что реально пойдёт на GPU (чистый PyTorch, не TF). Использовать как **второй проход** по сомнительным окнам с валидированным промптом **«Is this a sound of birds chirping or noise?»** (Nature Sci Rep 2025 — этот промпт дал лучший результат; добавление контекста «far in the background» поднимало AP с 0.54 до 0.79).

**Вывод:** двухступенчатый пайплайн onset.py (CPU, stage-1) → CLAP (GPU, stage-2 по сомнительным) сохраняет скорость и снижает FPR без переобучения. Для baseline этой ночью достаточно одного onset.py.

## 6. Измеримо этой ночью без xeno-canto / НЕ измеримо

### Измеримо БЕЗ xeno-canto (этой ночью)

- **Bird present/absent precision/recall** пайплайна на freefield1010 + warblrb10k + PolandNFC (анонимная загрузка, бинарные метки) — основная оценочная метрика без видовой разметки.
- **Производительность детектора stage-1** (onset.py): RTF, FPR на тишине/шуме — на наших WAV без ресэмпла.
- **CLAP zero-shot bird/noise AP** на тех же бинарных датасетах (GPU, веса CC0 анонимно).
- **BirdNET inference + видовой список** на наших записях (анонимная загрузка) — какие виды модель «слышит», sanity-check покрытия. *Без ground-truth это не точность, а инвентаризация предсказаний.*
- **Perch 1 эмбеддинги** через TFHub анонимно (если Kaggle ещё не настроен) — проверить few-shot кластеризацию.
- **Hard-negative проверка** domain-shift на ESC-50 / Watkins / UrbanSound8K (форма) — ложные срабатывания на не-птичьих звуках.

### НЕ измеримо без xeno-canto (нужен ключ/разметка)

- **Видовая точность (species-level accuracy) для конкретных видов СЗ России** — нет видовых эталонов РФ без xeno-canto.
- **Few-shot качество на редких локальных видах** (соня, выхухоль и т.п.) — нужны видовые примеры для построения k-NN эталонов.
- **Perch 2 (perch_v2_cpu)** — нужен Kaggle-аккаунт; этой ночью без него работаем на Perch 1 (TFHub).
- Любая метрика, требующая видовой ground-truth: confusion matrix по видам, per-species recall.

## 7. Horizon «к июлю»: foundation-модели для fine-tune / эмбеддингов

Все кандидаты ниже — **PyTorch → работают на нашем GPU (cu130) без ограничений TF/JAX**. Это их главное преимущество над Perch/YAMNet на нашем железе.

| Модель | Лицензия | Загрузка | Назначение | Заметки |
|---|---|---|---|---|
| **BirdAVES** (bioxn-large) | MIT | `pip install esp-aves` / wget (~1.2 GB), ONNX для CPU | SSL-эмбеддер птиц, per-frame (50 мс) | **+20% vs AVES**, обучен ~3076 ч биоакустики. Per-frame идеален для event-сегментации. Нужен ресэмпл 48→16 kHz. PyTorch на GPU |
| **BEATs** (iter3+) | MIT | прямая ссылка microsoft/unilm (~360 MB) | SSL audio encoder, ~90M | SOTA на BEANS несмотря на general-audio обучение → может лучше обобщаться на новую экосистему СЗ России. 16 kHz mono |
| **PaSST** | Apache 2.0 | `pip install hear21passt`, авто-веса | general-audio transformer | **Сильнейший general-audio на BirdSet: F1=0.704.** Лучший кандидат если появится немного разметки для fine-tune. 16 kHz mono |
| **AST** | BSD-3-Clause | HF `MIT/ast-finetuned-audioset-...` анонимно | ViT по спектрограмме | Самая простая интеграция (HF Transformers), хорошая отправная точка для transfer learning |
| **CLAP (LAION)** | Apache 2.0 / CC0 веса | `pip install laion-clap`, HF анонимно | zero-shot text-audio | Единственный zero-shot по текстовым промптам — разведка гипотез без разметки. Также stage-2 детектор (см. §3) |
| **BioLingual** | (биоакустич. CLAP) | — | специализированный CLAP | **в 2.2x лучше LAION-CLAP на BEANS** — альтернатива, если CLAP слаб на наших записях |
| **Perch 2 fine-tune** | Apache 2.0 | Kaggle | дообучение головы на эмбеддингах | TF CPU-only у нас — fine-tune головы лёгкий, но база на CPU |

**Стратегия к июлю:**
1. **Эмбеддер на GPU:** BirdAVES (птицы, per-frame, MIT) или BEATs (обобщение, MIT) — оба PyTorch, идут на RTX 2060S. Генерируют эмбеддинги для кластеризации/few-shot **без разметки**.
2. **Если появится разметка:** fine-tune PaSST (F1=0.704 на BirdSet) или головы поверх Perch 2 эмбеддингов.
3. **Zero-shot разведка:** CLAP / BioLingual для проверки гипотез по тексту без обучения.

> Неопределённость: RTF всех horizon-моделей на нашем конкретном железе не измерен; ONNX-версия BirdAVES даёт CPU-fallback, но медленно. Цифры качества (F1, +20%, 2.2x) — из публикаций на других датасетах, не на записях СЗ России.

## Итоговая сводка (recommendation-first)

1. **Классификатор пилота:** Perch 2 (Apache 2.0, SOTA-эмбеддинги, few-shot) — главный; BirdNET для быстрой видовой инвентаризации с учётом NC-лицензии.
2. **Детектор stage-1:** onset.py (CPU) + CLAP (GPU) на сомнительных. NDSI — только минутный pre-filter.
3. **Этой ночью без xeno-canto:** меряем bird present/absent precision/recall на freefield1010/warblrb10k/PolandNFC, RTF детектора, CLAP AP — всё анонимно.
4. **Креды для следующего шага:** xeno-canto ключ (видовая точность РФ) + Kaggle (Perch 2) — оба бесплатны.
5. **Горизонт:** PyTorch foundation-модели (BirdAVES/BEATs/PaSST/CLAP) обходят TF-GPU-блокер и пойдут на RTX 2060S.
