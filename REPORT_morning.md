## 2. Что именно здесь сделал

Оркестрация шла волнами: 4 параллельных агента собрали векторы по непересекающимся директориям,
затем интеграция, затем аудит-петля. Конкретные артефакты:

- **`faun/embeddings.py`** — единый владелец батч-экспорта эмбеддингов: протокол `Embedder` +
  `PerchEmbedder` (1280-dim, 32 кГц, окно 160000) и `YamnetEmbedder` (2048-dim, 16 кГц,
  concat(mean,max)) поверх замороженных wrapper'ов экспериментов; `embed_batch`, `EmbeddingCache`
  (.npz). Тяжёлый TF — лениво, поэтому препроцессинг тестируется без TF (монкипатч + проверка формы).
- **`faun/labeling/`** — мультимодельная авто-разметка (директива № 2): `batch_label` гоняет каждую
  модель по сегментам, пишет `detections.jsonl` с псевдо-метками `model:perch`/`model:birdnet`,
  считает консенсус (вид, на который согласились обе модели), опционально экспортирует
  `embeddings.npz`. `training_candidates` — **жёсткий лицензионный гейт**: метки BirdNET
  (CC BY-NC-SA, ShareAlike «заражает» дообученную голову) никогда не попадают в обучающую выборку
  коммерческой модели — только в инвентаризацию для эксперта.
- **`faun/datasets/`** — загрузчик iNatSounds (директива № 3): дерево `вид/клип` → manifest / словарь
  видов / стратифицированный сплит. iNatSounds — **первый источник с истинными видовыми метками**
  (у raw180 их нет вовсе).
- **`faun/retraining.species_eval`** — оценка видовой пробы: per-species recall, macro-F1, матрица
  ошибок, CV-доверительный интервал. **Переиспользует** существующий мультиклассовый `train_probe_cv`
  — нового пакета обучения не плодили.
- **`faun/health.py` + `/healthz`** и **`deploy/`** (директива № 1) — лёгкий health-handler и
  staged-артефакты деплоя.
- **CLI**: `faun batch-label`, `faun fetch-dataset`, `faun eval-species` (аддитивно, тяжёлые импорты
  ленивые).
- **Фронт**: переработаны `index/dashboard/review.html` + общие `app.js`/`styles.css` в единый
  визуальный стиль (демо-facing для заказчика), контракт API и имена окон сохранены; добавлен
  бинарный DOM-инвариант-тест.
- **Кластерные скрипты**: `scripts/train_inatsounds.sh`, `scripts/batch_label_raw180.sh` — каждый
  запускается одной командой на cluster-alex (для ручного запуска утром).

## 3. Что это принесло

- Все три директивы переведены из «идеи в чате» в исполнимый код с тестами и launch-скриптами —
  утром остаётся запустить на кластере, а не писать с нуля.
- Заказчик получает обновлённый, презентабельный веб-интерфейс уже сейчас (compute не требует).
- Лицензионный риск BirdNET (CC BY-NC-SA) закрыт **в коде** гейтом, а не только на словах — это
  снимает юридическую мину с продуктовой модели.
- Честность метрик сохранена: появилась инфраструктура видовой оценки, но ни одной цифры,
  выдаваемой за «точность по видам», не добавилось — всё синтетическое помечено.

## 4. С какими проблемами столкнулся

- **Ограничения среды** (главное): нет TF/Docker/GPU/данных/кредов локально — поэтому весь тяжёлый
  ML валидируется на синтетике/фикстурах, а реальные прогоны вынесены на кластер.
- **Два несовместимых YAMNet-вектора в репозитории**: `YAMNetAdapter.embed` даёт 1024 (mean), а
  `YamnetEmbedder` — 2048 (concat). Скрещивание обучения и оценки молча падало бы. Решено громким
  гейтом (см. п.7) + вынесено в открытый вопрос ML-лиду.
- **Прокси на localhost** (407) блокирует Playwright-скриншоты — заменены обязательным бинарным
  DOM-инвариант-тестом (скриншоты опциональны).

## 5. **ЧТО НЕ СДЕЛАЛ (и почему — честно)**

- **Не развернул v2 на сервере** (директива № 1). Нет доступа на запуск + на кластере крутится
  замороженное демо v1 (порты :8003/:8005/:9000, трогать нельзя) — это иной класс риска без вашего
  явного «go». Отдан `/healthz` + Dockerfile + compose + runbook + предложение порта 8010. **Docker
  локально отсутствует — образ не собирался**, только статически проверен.
- **Не разметил реальные записи raw180** (директива № 2). Нет TF и нет 180 ГБ данных локально. Код и
  тесты готовы; реальный прогон — одной командой через `scripts/batch_label_raw180.sh` на кластере.
- **Не обучил видовую модель на iNatSounds** (директива № 3). Нет датасета (нужна ручная закачка на
  кластер, кредов Kaggle/HF нет), нет GPU. Готов каркас loader→embed→train→eval и
  `scripts/train_inatsounds.sh`.
- **Видовой точности — ноль цифр.** Все числа на синтетике помечены `SYNTHETIC — not a species
  metric`. Реальная цифра появится только после прогона на iNatSounds на кластере.

## 6. Какие баги вскрыл (аудит-волна)

- **Блокер:** `batch_label` передавал классификатору объект `Segment`, а контракт ждёт waveform-массив
  на 16 кГц — реальные Perch/BirdNET упали бы на кластере; локальные stub-тесты это маскировали.
- **Блокер:** проба и эмбеддер могли разойтись по размерности (YAMNet 1024 vs 2048) — sklearn упал бы
  с невнятной ошибкой.
- **Утечка честности:** `eval-species` жёстко ставил `synthetic=False` — на игрушечном датасете число
  пометилось бы как реальная видовая метрика.
- Мелочи: `EmbeddingCache.load` не отличал битый .npz; один тривиально-зелёный тест; двойное чтение
  файлов в экспорте эмбеддингов.

## 7. Что починил

- `batch_label` теперь нарезает клип и ресемплит в 16 кГц перед классификацией (как `run_pipeline`),
  единым проходом + переиспользует `embed_batch` (убрано двойное чтение). Добавлен тест-контракт,
  проверяющий, что классификатор получает `ndarray@16k`.
- `species_eval` падает явным `ValueError` при несовпадении размерностей пробы и эмбеддингов (+тест,
  +заметка в `docs/training.md`). Канонизация 1024-vs-2048 вынесена в открытый вопрос.
- `eval-species --real`: по умолчанию метрика честно помечается `SYNTHETIC`; реальную выдаёт только
  явный флаг.
- `EmbeddingCache.load` → понятный «corrupt embedding cache» (+тест); тривиальный тест заменён на
  реальную проверку.
- Повторная верификация двумя ревьюерами: оба блокера закрыты, новых не внесено.

## Как запустить (локально, без TF)

```bash
cd /Users/user/sandbox/faun
pip install -r requirements-pipeline.txt        # TensorFlow НЕ нужен

# веб-демо (новый интерфейс) + health
FAUN_JOBS_ROOT=/tmp/faun_jobs python -m uvicorn faun.api:app --port 8765
#   http://127.0.0.1:8765/  ·  /dashboard  ·  /review  ·  /healthz

# авто-разметка на фикстуре (Stub, без TF)
python -m faun.cli batch-label --archive tests/fixtures/traps_mini --out /tmp/det.jsonl --models stub

# валидация датасета iNatSounds (мини-фикстура)
python -m faun.cli fetch-dataset --root tests/fixtures/inatsounds_mini
```

На кластере (одной командой, утром/по разрешению): `scripts/batch_label_raw180.sh`,
`scripts/train_inatsounds.sh`. Деплой: `deploy/README.md`.
