# Утренний отчёт — прототип Faun (TDOA + переразметка + петля дообучения)

**Дата:** 2026-06-17 (овернайт-прогон). **Статус:** ✅ готово, слито в `main`.
**Тесты:** 253 passed, 1 skipped (gate-7b, требует TF — запустится на кластере). CI-гейты зелёные.

Прототип из 3 окон, переиспользованное ядро TDOA с честной маркировкой, замкнутая петля
дообучения **только на человеческих метках**, и документ о честности метрик. Заказчик (Yandex
Cloud + Президентский фонд природы) увидит работающий контур загрузка → дашборд → переразметка.

## Что нового (8 коммитов)

**Бэкенд / ядро:**
- `faun/detections.py` — центральная абстракция **детекции**: вырезанное событие + метки с
  происхождением (`source`) и жизненным циклом (`status`), атомарный JSONL. Инвариант
  `is_ground_truth` — истина только `expert`/`ranger` + `confirmed`/`corrected`.
- `faun/localization/` — ядро **TDOA** перенесено из хакатона (`legacy/edge/tdoa`). `localize_event`
  при <3 ловушках возвращает `insufficient-traps` (без выдуманной точки), при ≥3 —
  `tdoa-synthetic-validated`. **Честно:** математика валидна только на синтетике, на реальных
  секундных таймстемпах заблокирована (нужна мс-синхронизация часов).
- `faun/api.py` — `run_pipeline` теперь пишет `detections.jsonl` + **реальные аудиоклипы**
  `segments/<id>.wav`, вырезанные из оригинала на исходной частоте (48 kHz). 4 новых роута:
  `GET /jobs`, `GET /jobs/{id}/detections`, `GET /jobs/{id}/segments/{det}.wav`,
  `POST /jobs/{id}/detections/{det}/label` (потокобезопасная правка через `fcntl.flock`).

**Дообучение:**
- `faun/retraining.py` — `retrain_from_labels`: фильтр **только человеческих** меток (модельные
  `pseudo` отбрасываются — жёсткий негативный гейт), при нуле таких меток — явный отказ, не пустой
  fit. Кросс-валидация (StratifiedKFold) с доверительным интервалом или честной пометкой «n мал».
- CLI: `faun retrain --labels <csv> --model yamnet --out probe.pkl` и
  `faun export-clips --job <dir> --out clips.zip` (орнитолог получает **реальные .wav**, не
  спектрограммы, + табличку-подсказку).

**Фронт (3 окна, vanilla JS, без сборки):**
- `/` — загрузка (папка/URL + координаты) → запуск → очередь «N из M» → ссылка на отчёт.
- `/dashboard` — список job'ов + Leaflet-карта позиций ловушек (точка-источник рисуется только
  при реальной локализации, сейчас её нет — честно показываем только ловушки).
- `/review?job=<id>` — таблица детекций с **аудиоплеером реального клипа**, цветным бейджем
  источника (модель/эксперт/лесник) + уверенность, и полем переразметки лесником.

**Документ:**
- `experiments/report/METRICS_HONESTY.md` — что на самом деле меряет каждая цифра: ff1010 (0.905/0.860)
  = птица/не-птица, ESC-50 (~0.99) = чирп vs шум; **видовой точности на данных заповедника пока нет**
  (нет ground-truth на raw180). Путь к реальным метрикам — через человеческие метки.

## Как запустить демо

```bash
cd /Users/user/sandbox/faun
pip install -r requirements-pipeline.txt          # + pytest (TensorFlow НЕ нужен)

# веб-демо
FAUN_JOBS_ROOT=/tmp/faun_jobs python -m uvicorn faun.api:app --port 8765
# открыть http://127.0.0.1:8765/  → загрузить папку ловушки (одна папка = одна ловушка, с info.txt)
#   → дождаться done → «Открыть переразметку» → послушать клип, переразметить
# дашборд: http://127.0.0.1:8765/dashboard

# CLI (без сервера)
python -m faun.cli process <папка_ловушки> --out /tmp/r.csv
#   → рядом появятся detections.jsonl и segments/*.wav (клипы 48 kHz из оригинала)

# экспорт орнитологу и дообучение (дообучение — на кластере, нужен TF)
python -m faun.cli export-clips --job /tmp --out /tmp/clips.zip
python -m faun.cli retrain --labels their_labels.csv --model yamnet --out probe.pkl
# деплой пробы: YAMNET_PROBE_PATH=probe.pkl (YAMNetAdapter подхватит)
```

## Что осталось / отложено (не блокирует прототип)

- **Co-detection ≥3 ловушек** для реальной локализации — `localization` сейчас `null` (карта честно
  показывает только ловушки). Нужен механизм «манифест → сигналы по ловушкам».
- **Реальная TDOA на данных** — заблокирована: секундные таймстемпы грубее нужного в ~16000×.
  Запрос в заповедник: есть ли мс-синхронизация часов, timestamp внутри WAV и его точность.
- **Реальные видовые метрики** — после первой партии экспертных меток (`export-clips` → орнитолог
  → `retrain`, ≥300 меток для CV с CI).
- **Офлайн-карта** — сейчас Leaflet-тайлы с CDN (unpkg); бандл тайлов — отдельная задача.
- **Параллельная обработка job** — сейчас последовательно (показываем позицию в очереди).
- **Дефолтный адаптер на кластере** — рекомендация Perch (Apache 2.0) вместо BirdNET (NC, некоммерч.).
