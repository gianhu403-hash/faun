# Утренний отчёт — Faun v2 production-ready (арх + ops + auth)

**Дата:** 2026-06-19 · **Ветка:** `feat/prod-ready` (от `main` `92585c9`) · **Бэкенд:** по-прежнему `stub`.

## Рекомендация (вывод вперёд)

Кодовая часть production-hardening **готова и проверена**: архитектура почищена до единых
владельцев, закрыты прод-долги (disk-leak, валидация входов, пины), добавлен простой
**HTTP Basic Auth** (логин-окно в браузере, env-gated, по умолчанию открыто). Все гейты зелёные:
**498 passed / 2 skipped, bandit 0 HIGH**, ни одного module-level `torch`/`tensorflow`, замороженные
сигнатуры целы. **Осталось одно действие — ваше:** мёрж в `main` + blue-green передеплой (нужны
кластер/tailnet и генерация пароля) — это Wave 5, ждёт живой сессии. Реального распознавания
видов как не было, так и нет (см. п.5) — это отдельный трек, кредами/данными/GPU.

## 1. Что сделано

Прошёл план v3 волнами через dynamic-workflows: контракты → сборка (3 параллельных вектора) →
интеграция → аудит (5 ревьюеров + мульти-вотинг) → доки. 6 коммитов на `feat/prod-ready`.

## 2. Что именно здесь (по трекам)

- **Архитектура.** Новый `faun/audio.py` — единственный владелец препроцессинга
  (downmix/resample/fit_window); `embeddings` ре-экспортит под `_`-именами (frozen-импорт для
  `training/dataset.py` цел, инвариант is-идентичности); `segmentation` и `perch_v2` делегируют.
  Новый `faun/pipeline.py` — `run_batch`: единое ядро segment→16k→classify→Detection; `run_pipeline`
  и `batch_label` стали тонкими обёртками, клипы row-aligned с детекциями. `is_ground_truth` +
  `TRAINING_EXCLUDED_SOURCES` сведены в `faun.detections` (retraining/labeling импортируют). Конфиг
  читается через `get_settings()` в api/sources/адаптерах/health. ADR-0002/0003 + `CONTEXT.md`.
- **Безопасность/ops.** Disk-leak: `run_pipeline` И `batch_label` чистят `<workdir>/_source` в
  `finally`. Basic Auth: middleware на всех роутах кроме `/healthz`, `hmac.compare_digest`,
  fail-closed на whitespace-кредах. Валидация `lat/lon` (WGS84, NaN/Inf→422) и длины меток.
- **Деплой.** `/healthz` version из env `FAUN_VERSION`; Dockerfile — digest-пин базы +
  `ARG FAUN_VERSION`; compose приведён к прод-правде (`100.64.0.1:8010`, том `faun-v2-jobs`).

## 3. Что это принесло

Один источник правды по препроцессингу/конфигу/ground-truth (меньше дрейфа), воспроизводимый
образ (пины + digest), и продукт, который можно показать заказчику за **логином** вместо открытого
URL — всё это без изменения замороженного контракта и без риска для живого сайта.

## 4. Проблемы по ходу

- **Запланированный облачный агент не доставил результат.** Routine отстрелялся вовремя, но
  запушить в репозиторий не смог (облачный агент = свежий checkout под другой идентичностью, без
  прав на push и без кластера). Работу доделала живая сессия — надёжнее. Урок записан в память.
- **`requirements-train.txt` был неустановим на кластере.** Потолок `torch<2.7` — а на cu130
  (CUDA 13) колёса начинаются с 2.9 (стоит 2.12.0+cu130). Чинить вслепую облаком нельзя — нужен
  был доступ к кластеру (см. п.7).

## 5. Что НЕ сделал (наверх — честно)

- **Реального распознавания видов нет.** Бэкенд деплоя остаётся `stub`. Реальный **Perch 2** —
  нужны Kaggle-креды; реальный **fine-tune** — нужны iNatSounds + GPU-go; **первой видовой цифры
  нет**. Синтетика помечена `SYNTHETIC` (вердикт `METRICS_HONESTY.md` не менялся).
- **Wave 5 (деплой) не выполнен** — мёрж `feat/prod-ready`→`main` и blue-green передеплой ждут
  вашей живой сессии (кластер/tailnet + генерация Basic-Auth пароля в gitignored
  `deploy/basic-auth.local.md`).
- Вне scope (июль/блокеры): S3-storage, CI/CD-на-кластер, rate-limiting на nginx.

## 6. Баги (найдены аудитом, подтверждены ≥2/3 голосов)

- `batch_label` НЕ чистил `_source` (асимметрия с `run_pipeline`) — для Я.Диск-прогона это
  десятки ГБ мусора рядом с `out.jsonl`.
- Basic Auth читался через path-хелпер (`.strip()`): пароль из пробелов → `None` → **тихо
  отключал авторизацию** (fail-open).
- Мёртвая `api.CLASSIFY_SR` и дубль `CLASSIFY_SR` в `labeling` (второй источник правды).

## 7. Что починил

Все подтверждённые находки закрыты и перепроверены (498 зелёных): симметричный disk-leak в
`batch_label`; verbatim-чтение кредов (`_env_secret_opt`, fail-closed); удалён мёртвый/дубль-конст.
Отдельно — по живому пробу кластера поднял `torch>=2.9,<2.13` (cu130-реальность), что заодно
закрывает **CVE-2025-32434** (RCE в `torch.load`, патч 2.6.0).
