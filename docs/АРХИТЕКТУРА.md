# Архитектура Faun (v2 — офлайн batch-pipeline распознавания видов птиц)

> Что это: оператор загружает архив записей с аудиоловушек (папка / URL / Яндекс.Диск), система
> находит звуковые события, классифицирует виды птиц и отдаёт CSV (трек, таймкод, вид, вероятность)
> + простой web-UI. Контур двухэтапный: **детектор звуковых событий → классификатор видов**.

## Поток данных

```
архив ловушек (локальная папка / http(s)-zip / Яндекс.Диск)
 → faun/sources.resolve_source        — резолв источника в локальную папку (защита от SSRF и zip-бомб)
 → faun/ingest.scan                    — скан папок A1..A5 + info.txt → Manifest (одна папка = одна ловушка)
 → faun/ordering                       — хронологическая сортировка + детект пропусков цикла записи (10 мин + 1 мин паузы)
 → faun/segmentation.SegmentExtractor  — downmix→resample 16k→onset-детектор; опц. волна 2 (плотные окна/тишина/NMS)
 → faun/pipeline.run_batch             — нарезка клипа → подготовка входа → классификация → Detection (row-aligned)
 → faun/classification.<адаптер>       — Perch 2 zero-shot по умолчанию; опц. проба / маска-чеклист / presence-gate
 → faun/output                         — results.csv [track,start_sec,duration_sec,species,probability]
                                         + results_meta.json + detections.jsonl + опц. presence/smoothed
```

## Модули `faun/` (одна-две фразы на каждый)

- **ingest** — сканирует папки ловушек и `info.txt`, строит Manifest (одна папка = одна ловушка A1..A5).
- **sources** — превращает URL / Яндекс.Диск / zip в локальную папку перед ingest; защита от SSRF и zip-бомб.
- **ordering** — упорядочивает записи по времени, ловит пропуски в цикле записи (10 мин записи + 1 мин паузы).
- **audio** — единственный владелец препроцессинга: downmix (стерео→моно), resample (soxr), fit_window.
- **segmentation** — режет запись на сегменты-кандидаты: onset-детектор (по умолчанию) + опц. волна 2.
- **ml/onset** — энергетический детектор начала события (отношение короткой энергии к длинной).
- **classification** — протокол `SpeciesClassifier` + адаптеры: Stub, BirdNET (**non-commercial!**),
  Perch (1280), Perch 2 (1536, ~14795 видов), PerchProbe, YAMNet; + `MaskedClassifier` (allow-list-чеклист).
- **embeddings** — единый владелец батч-экспорта эмбеддингов (Perch / Perch 2 / YAMNet), кэш npz.
- **pipeline** — переиспользуемый исполнитель «сегмент → классификация → Detection»; клипы row-aligned с детекциями.
- **output** — пишет CSV, sidecar-метаданные, `detections.jsonl`, опц. presence / smoothed.
- **detections** — центральная абстракция детекции (`Detection` + `Label`: source / status / ts).
- **retraining** — обучение лёгкой пробы поверх ЗАМОРОЖЕННЫХ эмбеддингов (LogReg / центроид) + калибровка.
- **training** — РЕАЛЬНЫЙ PyTorch fine-tune аудиотрансформера (PaSST / AST / BEATs); только кластер-GPU.
- **datasets** — `iNatSoundsDataset`: первый источник с ИСТИННЫМИ видовыми метками (у raw180 их нет).
- **labeling** — мультимодельная псевдо-разметка (Perch + BirdNET) + лицензионный гейт обучающего набора.
- **localization** — порт TDOA из legacy (триангуляция по разнице времён прихода); валиден только на синтетике.
- **jobs / storage / settings / obs / health** — изоляция батчей, локальное хранилище, конфиг, логи, `/healthz`.
- **api** — FastAPI (`/jobs`, results.csv, detections, segments, review, dashboard, `/healthz`; опц. Basic-Auth).
- **cli** — `faun process / batch-label / retrain / finetune / eval-species / export-*`.
- **spectrogram** — рендер PNG-спектрограммы для review (matplotlib подгружается лениво).
- **static** — vanilla-JS UI: index (загрузка), dashboard (карта + очередь), review (детекции + аудиоплеер).

## Архитектурные решения (ADR — короткие заголовки)

- **0001** — слой резолва источника (URL / Яндекс.Диск / zip → локальная папка).
- **0002** — единый владелец аудио-препроцессинга (`faun/audio`).
- **0003** — переиспользуемый исполнитель pipeline + контракт «словарь видов / размерность эмбеддинга».
- **0004** — региональная маска-чеклист (`MaskedClassifier`, allow-list).
- **0005** — калибровка вероятностей (temperature scaling, Guo 2017).
- **0006** — честная сегментация (плотные окна / фильтр тишины / NMS по IoU / сглаживание).
- **0007** — presence soft-gate + serve-калибровка.
- **0008** — прототипическая проба + класс «негатив».
- **0009** — demo polish (спектрограмма / экспорт Raven / фильтры review).

**Важно:** все волны 1–5 — **аддитивны и по умолчанию ВЫКЛЮЧЕНЫ**, поэтому golden-поведение
pipeline байт-в-байт совпадает с состоянием до них. Колонки CSV и замороженные сигнатуры
(`faun/INTERFACES.md`) не менялись.
