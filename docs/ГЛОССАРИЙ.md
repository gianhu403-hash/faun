# Глоссарий

> Каждый термин — одна фраза простым языком и, где полезно, ссылка на источник. Если термин здесь
> есть, а в тексте проекта он встретился без пояснения — смело давайте на эту статью ссылку.

- **embedding (эмбеддинг)** — вектор чисел, кодирующий суть аудиофрагмента (Perch 2 = 1536 чисел, YAMNet = 2048).
- **logit** — сырое число до softmax, может быть больше 1; это ещё НЕ вероятность. https://en.wikipedia.org/wiki/Logit
- **softmax** — превращает логиты в вероятности (в сумме дают 1). https://en.wikipedia.org/wiki/Softmax_function
- **temperature scaling / калибровка** — делим логиты на число T перед softmax; делает уверенность модели
  честнее. Guo et al. 2017 — https://arxiv.org/abs/1706.04599
- **ECE (Expected Calibration Error)** — насколько заявленная уверенность совпадает с реальной частотой попаданий.
- **linear probe (линейная проба)** — линейная голова (LogReg) поверх замороженных эмбеддингов, обученная на видовых метках.
- **prototype / prototypical network** — классификация по ближайшему центроиду класса (по косинусу).
  Snell et al. 2017 — https://arxiv.org/abs/1703.05175
- **zero-shot** — модель называет вид из большого словаря без дообучения на наших данных.
  https://en.wikipedia.org/wiki/Zero-shot_learning
- **held-out split** — тестовый набор, который модель не видела при обучении.
- **macro-F1** — F1 по каждому классу отдельно, затем среднее (не смещается в сторону частых классов).
- **onset detection** — поиск начала события по скачку энергии. https://en.wikipedia.org/wiki/Onset_(music)
- **NMS (Non-Maximum Suppression)** — убираем перекрывающиеся детекции, оставляя лучшую.
- **IoU (Intersection-over-Union)** — мера перекрытия по времени: пересечение / объединение.
- **GCC-PHAT** — оценка задержки сигнала между микрофонами (для локализации).
  https://en.wikipedia.org/wiki/Cross-correlation#Generalized_cross-correlation
- **TDOA (Time Difference of Arrival)** — разница времён прихода звука на разные ловушки → триангуляция;
  на реальных данных невозможна без миллисекундной синхронизации. https://en.wikipedia.org/wiki/Time_difference_of_arrival
- **soxr** — качественный ресэмплинг (смена частоты дискретизации). https://github.com/dofuuz/python-soxr
- **downmix** — стерео → моно усреднением каналов.
- **Perch 2** — модель Google для распознавания птиц (Apache 2.0, ~14795 видов). https://www.kaggle.com/models/google/perch
- **BirdNET** — классификатор птиц (Cornell), лицензия CC BY-NC-SA = **non-commercial** (используем только как
  второе мнение, не для обучения). https://github.com/kahst/BirdNET-Analyzer
- **YAMNet** — аудиоклассификатор Google (AudioSet, 521 класс).
  https://github.com/tensorflow/models/tree/master/research/audio/yamnet
- **PaSST / AST / BEATs** — аудиотрансформеры-бэкбоны для fine-tune. PaSST https://arxiv.org/abs/2110.05069 ·
  AST https://arxiv.org/abs/2104.01778 · BEATs https://arxiv.org/abs/2212.09058
