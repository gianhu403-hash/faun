Разбивка складывается: 803 (A1–A4) + 841 (RECORDER) + 9 (офис) + 3 (общие) = 1656. По типам:
1647 `.wav`, 7 `.txt`, 1 `.tsv`, 1 `.jpg`.

**Регион** — из `raw180/Инструкция.txt` (дословно): ловушки установлены 29.05.2026 «рядом с
деревней Ковкеницы Ленинградской Области (вблизи Нижне-Свирского заповедника)», порядок установки
A3, A1, A4, A2, синхронизация — хлопком в ладоши. `RECORDER` — отдельная ловушка «в сквере
Санкт-Петербурга». Офисная запись — «для тестирования батареек». Это совпадает с текущим пониманием
региона проекта (Ленинградская обл., не Нижегородская — про путаницу с Нижегородской см.
`docs/АУДИТ-2026-06-25.md`).

**Меток нет — проверено, а не предположено.** У каждой ловушки `A{1-4}/info.txt` — это телеметрия
устройства (CSV): `DATE,TIME,LON,LAT,BAT,TEMP,HUMI,FILE,GAIN,SAMPLE RATE,CHANNEL,NOTE`. Колонку
`NOTE` проверили по всем 4 папкам — она везде пустая (один пробел). То есть **ни в одной из 1656
записей нет метки вида, оставленной человеком** (лесником, орнитологом и т.п.).

**GPS есть, но это координаты устройства, а не подтверждённая граница заповедника.** Значения взяты
прямо из телеметрии `info.txt` (колонки LON/LAT), не выдуманы: A1 ≈ 60.65164N 33.23434E; A2 ≈
60.65144N 33.23444E; A3 ≈ 60.65155–60.65196N / 33.23432–33.23481E; A4 ≈ 60.65146–60.65152N /
33.23466–33.23498E. (В первых строках некоторых файлов стоит `000.00000W,00.00000S` — это означает,
что GPS ещё не поймал сигнал сразу после включения, дальше координаты уже реальные.) Это вывод
логов устройства, а не независимо проверенная граница заповедника — так и нужно подавать эти цифры
дальше.

### 3.2 Полный val-сплит: метаданные есть, звук — нет

- `val.json` (20 210 775 байт) — метаданные полного val-сплита iNatSounds, **распакованы и

- `val.tar.gz` (26 660 769 742 байта ≈ 24.8 ГиБ) — сам звук этого сплита. **Лежит на диске в сжатом

Значит: названия видов и число клипов на вид мы знаем (метаданные), а сами звуковые файлы физически
недоступны для прослушивания/обучения, пока архив не распакован.

### 3.3 Что там с млекопитающими (по метаданным `val.json`)

Всего категорий (видов/групп) в `val.json`: **5569**. По классам: Aves (птицы) 3846, Insecta
(насекомые) 745, Amphibia (земноводные) 650, **Mammalia (млекопитающие) 296**, Reptilia
(пресмыкающиеся) 32.

Из 296 категорий-млекопитающих только у **41** есть хотя бы одна реальная запись (annotation) в
val-сплите — у остальных 255 это просто строка в таксономии без единого клипа. Топ по числу записей
(вид | название | сколько записей): Canis latrans (койот, 100), Sciurus carolinensis (серая белка,
100), Tamias striatus (бурундук, 100), Tamiasciurus hudsonicus (американская рыжая белка, 100),
Vulpes vulpes (лисица, 65), Capreolus capreolus (косуля, 59), Phascolarctos cinereus (коала, 38) —
и ещё 34 вида с меньшим числом записей (от 1 до 32). Полный список — в `val.json` кластера, здесь
не приводим целиком, чтобы не создавать видимость «официального списка».

Про целевые виды проекта отдельно:

- **Садовая соня (Eliomys quercinus)** — **числится** в `val.json` как категория (id 5465,
  семейство Gliridae, отряд Rodentia), но у неё **0 записей** в val-сплите. То есть даже крупнейший
  открытый биоакустический датасет знает, что такой вид существует, но ни одного звукового примера
  для него не даёт.
- **Выхухоль (Desmana moschata)** — **отсутствует полностью** среди всех 5569 категорий. Проверили
  и по слову «Desman», и по всему семейству Talpidae (кротовые) — там нашёлся только «Parascalops
  breweri» (североамериканский крот, другой вид, тоже 0 записей).

**Важная оговорка:** список из 41 вида выше — это не «данные, готовые к использованию прямо
сейчас», а «данные, которые появятся, если распаковать `val.tar.gz` (24.8 ГиБ)». Даже после
распаковки среди них нет ни садовой сони, ни выхухоли — целевых видов проекта.
