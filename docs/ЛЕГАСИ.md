# Legacy: что заморожено и почему (v1-hackathon)

> Весь хакатонный код заморожен в папке `legacy/` и на git-теге **v1-hackathon**. CI его НЕ гоняет
> (`legacy/tests/` исключён из прогона). Демо v1 продолжает крутиться на `faun.antopkin.ru/v1/`
> (внутренний адрес tailnet `100.64.0.1:8003`). Импорты внутри `legacy/` мы НЕ чиним — это архив.

## Дерево `legacy/`

```
legacy/
├── edge/                     # «на краю» — real-time обработка хакатона
│   ├── audio/                # YAMNet-голова: yamnet_forest_classifier_v7.keras (~6.4 MB, в git)
│   │                         #   6 классов ИМПУЛЬСНЫХ звуков (бензопила / выстрел / топор / двигатель / огонь / фон)
│   ├── decision/decider.py   # гейт по confidence / TDOA / разрешениям (ALERT / VERIFY / LOG / SAFE)
│   ├── tdoa/                 # триангуляция: triangulate.py (GCC-PHAT, скорость звука 343 м/с), distance.py
│   └── drone/                # управление дроном (протокол, не реальный полёт)
├── cloud/                    # «в облаке» — инфраструктура Yandex Cloud v1
│   ├── agent/, workflows/    # RAG-агент + Yandex Workflows (LLM + retrieval)
│   ├── notify/               # Telegram-боты, Slack, email рейнджерам
│   ├── db/                   # YDB-схема (инциденты / разрешения / рейнджеры)
│   ├── interface/, integrations/, analytics/, vision/
├── devices/, simulator/, gateway/   # LoRa-mesh, симулятор TDOA-задержек, LoRa-gateway
├── demo/, graphs/            # презентационные скрипты, визуализация
└── tests/                    # старые тесты v1 (CI их не запускает)
```

## Почему всё это заморожено

Продукт v2 полностью переписан в **офлайн batch-pipeline распознавания видов птиц** (14795+ классов).
А v1 был про другое: **6 импульсных классов** (резкие техногенные звуки), **real-time**-обработку
и **триангуляцию источника**. Триангуляция на реальных данных неосуществима — нужна
миллисекундная синхронизация часов ловушек, а есть только секундная сетка; поэтому в v2 она
осталась только как валидная-на-синтетике справка (см. `faun/localization` и
`experiments/report/METRICS_HONESTY.md` раздел 6).
